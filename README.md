# NoGuru review

[Open the website](https://vimo33.github.io/noguru-review/) · [Compare logo options](https://vimo33.github.io/noguru-review/brand-options.html)

A static website preview for feedback, not a customer launch. The provider/terms status and risk disclosures remain part of the review. No account, payment, analytics or trading backend is included.

The `site/` folder contains the reviewed static pages and assets. Paths use the `/noguru-review/` project prefix. The Pages workflow uploads only this folder. Changes to `main` deploy through GitHub Actions; confirm deployment success before treating a revision as live.

Keep future updates limited to reviewed website material. Do not add account records, research, transcripts, operational configuration or credentials.

Original operator pages and documented supplier answers govern product mechanics, prices, subscription terms and setup. Improve clarity and organization while retaining meaning, useful examples and source depth. Read and date the exact source before calling an answer unknown; record genuine contradictions, legal uncertainty and unreproducible empirical claims separately, preserving prior evidence. These editorial rules add no approval gate.
